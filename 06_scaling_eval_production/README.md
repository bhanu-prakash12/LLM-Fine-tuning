# Topic 6 — Scaling, Evaluation & Production Fine-Tuning

Builds the production path around the Topic 2 LoRA model: a real evaluation
harness, a real file-based model registry, real latency-percentile
computation, a canary-rollout simulation with automatic rollback, plus the
distributed-training ladder and vLLM serving reference for when you have a
GPU.

## What you'll learn

- Evaluation categories: loss, task accuracy, instruction following, human
  preference/LLM judge, regression tests, safety tests
- Model registry: version + metrics + stage tracking
- TTFT, TPOT, p50/p95/p99, tokens/sec
- The checkpoint → registry → staging → shadow → canary → production path
- The distributed-training ladder: 1 GPU → DP → FSDP → TP → PP

## Contents

- `data/support_tickets.json` — the shared dataset (copied from Topic 1)
- `requirements.txt` — Python packages needed
- `scaling_eval_production.ipynb` — the notebook
- `model_registry.json` — generated by running the notebook (a real artifact from the registry demo)
- `README.md` — this file

## How to run

**Recommended: Google Colab (free tier, T4 GPU)** — upload this folder,
open the notebook, set Runtime → GPU (T4), run all cells. Loads the real
Topic 2 LoRA model for evaluation (you'll need to point it at your saved
adapter).

**Locally without a CUDA GPU** — safe to run. The evaluation harness, model
registry, latency-percentile math, and canary-rollout simulation are all
real, runnable CPU-safe work using deterministic stand-in baselines instead
of a real trained model; loading the real LoRA model and vLLM serving are
skipped with a clear message.
